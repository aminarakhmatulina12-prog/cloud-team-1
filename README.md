# Cloud Team Project

Учебный проект по дисциплине «Основы облачных технологий».

## Цель проекта

Создание небольшого каталога облачных сервисов и сравнение моделей IaaS, PaaS и SaaS.

## Выполненные задачи

- Создан каталог облачных сервисов.
- Выполнено сравнение IaaS, PaaS и SaaS.
- Добавлены примеры облачных сервисов.
- Использованы Issues, ветви и Pull Requests.
